# 🚦 E-Challan Tracker

> Real-time Vehicle E-Challan verification portal with interactive bike loading animation and instant Parivahan records inspection.

**Created & Engineered with full credit to [Himanshu Kumar](https://github.com/FightClubMember)**

---

## 🌟 Key Features
- **Instant Challan Discovery**: Query traffic violation records, pending fine amounts, virtual court transfer status, and offense breakdown.
- **Custom Bike Loader Animation**: Interactive CSS & SVG running motorcycle animation with rotating spokes, dynamic rider posture, and exhaust smoke trail during API calls.
- **Direct Parivahan Gateway Sync**: Configured with the high-speed Challan API endpoint (`api.allprinthub.in`).
- **One-Click Payment Routing**: Quick links to direct official government settlement portals (`echallan.parivahan.gov.in`).
- **Responsive Glassmorphism UI**: High-contrast, mobile-friendly design with Indian HSRP license plate styling.

---

## 🚀 Getting Started
Simply clone or download this repository and open `index.html` in any web browser:

```bash
git clone https://github.com/FightClubMember/challan-checker.git
cd challan-checker
```

Double click `index.html` or serve with any static HTTP server.
